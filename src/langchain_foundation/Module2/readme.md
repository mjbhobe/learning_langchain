# Module 2

In this module you will build upon the fundamentals you learnt in Module1. We will introduce sophisticated techniques like MCP, 

1. We'll start by understanding how to **interface your agent with the Model Context Protocol (MCP)**. This open source standard, developed by Anthropic, has been one of the biggest development in the world of AI agents.
2. Sometimes there is some information that the agent should know when it's running. For example, Is the current user an employee of the company? What is his/her preferred language? This can be achieved by **enabling our agent with runtime context and customize its state** so it keeps track of more that just the messages in its memory.
3. Next, we'll learn anout **multi-agent systems**, which allow your applications to handle longer and larger tasks that would be too much for a single agent to process on its own.
4. Finally, we'll close with a **Wedding planner (multi-agent) application** that leveraged techniques we'll learn in thius module. We'll be building a _destination-wedding planning dream team_ of agents.
